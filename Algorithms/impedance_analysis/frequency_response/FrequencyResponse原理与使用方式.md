# Frequency Response 原理与使用方式

## 原理

频率响应比较同一频率下输出与输入的复数幅值和相位。每个扫频点先由PLL和同步检波得到输入、输出幅值与相位，再计算：

```text
线性增益 = 输出幅值 / 输入幅值
相位响应 = 输出相位 - 输入相位 + 校准值
```

模块同时给出 Q15增益、百分比、毫分贝、毫度和等效延迟。`gainMilliDecibels=6021` 约为+6.021 dB，`gainMilliPercent=200000` 表示200.000%，即2倍增益。

等效延迟把当前频点的相位差换算成时间。例如1 kHz时-45度对应约125 µs。它是相位按一个周期折返后的等效值，不一定等于宽带系统真正的群时延。

## 使用方式

```c
FrequencyResponse_Result point;

if (inputDetection.stable && outputDetection.stable &&
    FrequencyResponse_calculate(
        &inputDetection,
        &outputDetection,
        pllOutput.frequencyMilliHz,
        phaseCorrectionMilliDegrees,
        &point)) {
    /* 保存 point，随后改变激励频率。 */
}
```

一个完整扫频点应经历：

```text
设置DDS/DAC频率
→ 等待模拟电路稳定
→ 等待PLL锁定
→ 重置同步检波器
→ 等待同步检波稳定
→ 读取频响点
→ 进入下一频率
```

不能刚改变DAC频率就立即读取，否则测到的是过渡过程。

## 截止频率和带宽

本模块只计算单个频点。应用层保存一组扫频结果后，可以寻找相对于通带增益下降约3.010 dB的位置作为截止频率。若频点较稀，可以在相邻两个扫频点之间插值，但插值不能替代足够密的扫频。

带通系统可分别寻找低、高两个-3 dB点，两者之差为带宽；谐振峰值频率除以带宽可以估算Q值。

## 注意事项

- 输入和输出必须使用相同物理单位或经过明确的比例校准。
- 输入幅值接近零时增益会非常大且不稳定，函数会拒绝严格零输入，应用层还应设置更高门限。
- 相位校准可能随频率变化，宽带测量应使用校准曲线而不是一个固定常数。
- dB使用定点log2近似，足以显示和扫频判断，但不是双精度数学库结果。
- 相位输出折返到 -180～180度；绘制波特图时需要应用层进行相位展开。
- 等效延迟不是多频点群时延。群时延需要根据相邻频点的展开相位斜率计算。
- 每个频率点的激励幅值应已知且稳定，避免信号源随频率变化被误认为被测电路响应。
- 功放扫频还必须检查输出削顶、负载功率和温升，不能只看增益。
