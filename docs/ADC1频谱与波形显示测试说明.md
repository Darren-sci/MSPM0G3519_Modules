# ADC1频谱与波形显示测试说明

## 1. 功能开关

测试ADC1时使用：

```c
#define ENABLE_LCD             (1)
#define ENABLE_ADC0_MULTI      (0)
#define ENABLE_ADC1_FAST       (1)
#define ENABLE_ADC1_ANALYZER   (1)
```

其余DAC、PWM和SPWM开关先设为0。ADC1输入为PB27，信号发生器地与开发板
GND必须共地。

## 2. 推荐的第一个测试信号

建议先使用容易观察和测频的正弦波：

```text
波形：正弦波
频率：10 kHz
幅度：1.0 Vpp
直流偏置：+1.65 V
负载设置：High-Z
```

这样PB27理论电压范围是1.15～2.15 V，处于0～3.3 V安全范围内。禁止直接
输入带负半周的零偏置正弦，也不能超过VDDA。如果信号发生器按50 Ω负载
标注幅度，而ADC实际是高阻输入，应检查示波器实测幅度是否变成设定值两倍。

## 3. 屏幕内容

上电默认显示全屏示波器页：

- KEY1：切换到示波器页。
- KEY2：切换到频谱页。

示波器页的横轴固定在屏幕中央，ADC码2048对应零电平，0和4095分别对应
负、正满量程。它先在当前1024点真实采样中寻找带迟滞的上升沿，再尽量截取
三个完整周期，使周期波形不会随DMA块起点左右漂移。显示点少于屏幕横向像素
时进行线性插值并连接相邻点；显示点更多时改画每列的最小值—最大值包络，
避免简单抽点漏掉尖峰。示波页面不再显示独立的时域F，峰峰值按照3.300 V
标称ADC参考电压换算并显示为伏特，同时显示触发状态；精密测量时应再使用
实测VDDA或模拟前端标定值替换标称参考电压。

频谱页左侧显示现有SignalAnalyzer根据同一批ADC数据计算的0～Fs/2单边
幅度谱，横轴位于图框底部，幅值只向正Y方向显示，H1～H6会标在各自谱峰
附近。右侧固定列出H1～H6的实测频率和峰值幅度Vpk；H1频率使用插值后的
F0，其余谐波显示各自检测频点，超出奈奎斯特范围或未检测到时显示`---`。
幅值按照3.300 V标称ADC参考电压换算，底部继续显示THD。

频谱纵轴按当前最大交流谱线自动缩放，适合观察主频和谐波位置，不代表固定
dB刻度。LCD默认每64个DMA块刷新一次，切换页面后会在下一块数据到来时立即
刷新。主循环对每个实际取得的完整DMA块运行分析，达到刷新间隔时复制当前块，
释放DMA缓冲区后再使用安全快照绘图。刷新过程中仍可能跳过完整数据块，顶部的
`DROP`会显示累计数量，但当前显示帧不会被DMA中途改写。

为避免8080接口整屏重画产生闪烁，标题、边框、网格和右侧栏框只在首次显示或
KEY1/KEY2切页时绘制。正常刷新仅擦除上一条波形或谱线并恢复其经过的网格，随后
绘制新数据；DROP、测量值和H1～H6文字也只覆盖各自的小区域，不再先清空整屏。

绘图前还会根据F0估算基本周期，并在其附近寻找使相邻周期最一致的采样间隔。
稳定的谐波、方波或削顶波仍然可以通过；如果一帧中出现明显不连续、周期间
平均差异过大或大跳变点过多，本次示波和频谱均不刷新，LCD保持上一幅已通过
校验的画面，并在下一完整数据块立即重试。

## 4. 采样率校准

`ADC1_ANALYZER_SAMPLE_RATE_HZ` 当前根据50 kHz已知信号、原显示12.536 kHz
校准为3988513 Hz。ADC1是自由运行模式，屏幕频率是否准确取决于这个参数。
更换时钟或采样配置后，可输入已知频率信号并按下式重新修正：

```text
新采样率 = 当前填写采样率 × 信号源频率 ÷ 屏幕测得频率
```

把结果重新填写到 `ADC1_ANALYZER_SAMPLE_RATE_HZ`，再次烧录并复测。校准后
再依次测试1 kHz、50 kHz和100 kHz正弦，确认频率测量和频谱峰位置一致。

## 5. 后续推荐信号

- 方波：10 kHz、1 Vpp、1.65 V偏置，用于观察奇次谐波。
- 双音：10 kHz与30 kHz叠加，用于检查频谱能否分开两条谱线。
- 脉冲：可用于检查包络显示是否保留窄脉冲；当前自动触发主要针对周期波形。
